# Smart Login UI

A modern smart login interface built with vanilla JavaScript.

## Features
- Real-time form validation
- Email format validation
- Password strength meter
- Toggle password visibility
- Save user session with localStorage
- Logout flow
- Dark / Light mode toggle
- Clean UI interactions

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## What I Learned
- DOM manipulation
- Event handling
- Form validation logic
- State management with localStorage
- Writing cleaner and refactored JavaScript
